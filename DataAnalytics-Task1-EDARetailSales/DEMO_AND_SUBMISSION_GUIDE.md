# Demo, LinkedIn, and Submission Guide

## 1. Upload the project to GitHub

Repository: <https://github.com/memoon-naveed/OIBSIP>

Upload the **folder itself**, not only the ZIP file, so the final path is exactly:

```text

```

Make sure the folder contains the notebook, dataset, README, CSV outputs, screenshots, and supporting files. A suitable commit message is:

```text

```

## 2. Record the demo video

Use `screenshots/00_demo_title_card.png` as a static full-screen opening for at least two seconds. It already contains the three required details:

```text
Memoon Naveed
Assigned Track: Data Analytics
Task 1: EDA on Retail Sales Data
```

Suggested 3-minute walkthrough:

1. **0:00–0:02 — Title card:** show the supplied title card without movement.
2. **0:02–0:25 — Project overview:** show the GitHub folder and README.
3. **0:25–0:45 — Data inspection:** show the dataset shape, types, null check, and descriptive statistics.
4. **0:45–1:15 — Time trends:** explain the monthly and quarterly chart, especially the Q4 peaks.
5. **1:15–1:40 — Customers:** show the age-group and gender analysis.
6. **1:40–2:05 — Products:** show best-selling products and category revenue.
7. **2:05–2:30 — Deeper insight:** show the correlation heatmap and seasonal volume-versus-value chart.
8. **2:30–3:00 — Conclusion:** finish with the recommendations and limitations in the notebook.

Keep the notebook zoomed so text is readable, move slowly, and narrate the business meaning rather than only naming each chart.

Copy the draft below, attach the demo video, and select the official **Oasis Infobyte** LinkedIn page when typing the tag.

---

I’m pleased to share Task 1 of my Data Analytics Internship at @Oasis Infobyte: Exploratory Data Analysis on Retail Sales Data.

Using Python, pandas, matplotlib, seaborn, and Jupyter Notebook, I analysed 102,771 retail transactions from January 2022 to December 2024 to understand sales growth, customer demographics, product performance, correlations, and seasonal behaviour.

Key findings:

- Total analysed revenue was $5.33M, with Q4 2024 producing the highest quarterly revenue.
- Sweaters were the best-selling product, while Clothing generated 67.35% of revenue.
- Summer had the highest transaction volume, but Winter achieved the highest average transaction value.
- The analysis led to practical recommendations for inventory planning, customer targeting, category cross-selling, and seasonal promotions.
